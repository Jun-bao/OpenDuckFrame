OpenDuckFrame 0.3.3

  • Frame generation now uses ODF-VFI, a four-stage model derived from RIFE 4.25, as its default model.
  • Reduced model processing overhead while retaining continuous caching and the existing Air window optimizations.
  • Existing enhancement profiles remain compatible. Scaling and super-resolution settings are unchanged.

ODF-VFI is a structural reduction of the upstream model, not a lossless-quality guarantee. Results depend on the source content.

This community build is ad-hoc signed and supports signed in-app updates. It is not Apple notarized.
