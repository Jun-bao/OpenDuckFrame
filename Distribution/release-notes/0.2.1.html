OpenDuckFrame 0.2.1

  • 默认配置使用“跟随来源”，恢复旧默认配置时也会纠正残留的全屏观看状态。
  • 修复修改“来源窗口尺寸”时自动切换到“全屏观看”、导致网页鼠标操作被阻挡的问题。
  • 来源窗口尺寸和超分输出尺寸继续按原规则生效；其他配置中明确保存的观看或交互模式保持原选择。

使用“跟随来源”时，增强画面与原窗口对齐，可直接操作网页。需要全屏观看时仍可手动选择；全屏观看模式不转发鼠标输入。

English

The default preset now reopens in Follow source mode, including when an older default configuration retained Fullscreen viewer. Changing the source window size no longer silently selects Fullscreen viewer and blocks webpage clicks. Source resizing and scaler output-size behavior are preserved. Explicit modes in other saved configurations are preserved.

This community build is ad-hoc signed, supports signed in-app updates, and is not Apple notarized. Requires macOS 14 or later on Apple silicon.
