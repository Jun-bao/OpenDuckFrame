OpenDuckFrame 0.2.0

  • For supported window sources, choose a source window size before scaling. The selected window is resized before capture; for the video itself to match the selected size, it must fill that window.
  • Improve single-window capture when child windows extend beyond the selected window.
  • Use frame generation and scaling separately or together, subject to the selected engines' compatibility.
  • Press Esc to leave fullscreen viewer and return to the source-aligned view; apply again to re-enter.

Window resizing requires Accessibility permission and a resizable window. Available engines and output sizes depend on the system and hardware; results depend on the source and engine.

This community build is ad-hoc signed and is not Apple notarized. macOS may block its first launch. If you trust the download, review the app under System Settings → Privacy & Security and choose whether to allow it.
