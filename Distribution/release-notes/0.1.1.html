OpenDuckFrame 0.1.1

New installations and the built-in Default preset now start with the same frame-generation settings in source builds and official downloads:

  • Frame generation enabled, using RIFE 4.25 at fast quality.
  • Experimental RIFE stream cache enabled for live window and display capture.
  • X2 multiplier and window output following the source.
  • Scaling remains off until selected by the user.

Existing saved profiles are retained. Selecting this configuration does not start capture or enhancement automatically. Other engines remain selectable; this release changes defaults and does not claim to fix their existing issues.

新安装与内置“默认”预设统一采用 RIFE 4.25、fast、连续缓存、倍率 X2 和跟随来源。 源码构建与官网下载使用相同默认值。已有保存配置继续保留。

This community build uses an ad-hoc code signature and signed update metadata. It is not Apple notarized.
